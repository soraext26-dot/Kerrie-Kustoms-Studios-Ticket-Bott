
## Install the dashboard as an app
The dashboard is a Progressive Web App (PWA). After Railway deploys the latest commit:
- Open the Railway public domain in Chrome or Edge.
- Use the **Install app** button if shown, or the browser's install icon/menu.
- On iPhone/iPad Safari, use Share > Add to Home Screen.
The app shell can load offline, but dashboard login, server settings and Discord controls require an internet connection and a running Railway service.
